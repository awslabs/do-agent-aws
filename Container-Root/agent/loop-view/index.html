        Control
        

        Run next fire starts the loop with /agent/loop-start.sh: it removes the STOP flag, and the loop fires at once when it has goals; a running loop is left alone. Pause loop sets the STOP flag with /agent/loop-stop.sh: the loop halts before its next fire, and a fire in flight finishes. Each answer is the loop's state read back after the action.
        

        The controls are off: set UI_LOOP_CONTROL=true in .env to run or pause the loop from here. The commands below still work.
