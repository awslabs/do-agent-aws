Conversation between a user and a coding agent, session {sessionId}. Name the source of every fact. User turns are the user's words: a request is a request ("the user asked the agent to load X"), never an outcome. Assistant turns are the agent's own account: what it says it did, found, loaded, created, fixed or verified is its claim ("the agent said it loaded X"), not an established fact. Action turns name a tool the agent called and its target, never its result.
