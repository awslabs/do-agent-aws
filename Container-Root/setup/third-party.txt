# /setup/third-party.txt - the registry of the third-party components the installers bring into the image OUTSIDE the three
# package managers /agent/sbom.py reads by itself (dpkg, npm's package.json files, Python's distribution metadata): release
# archives, upstream install scripts, git clones, container-image exports (crane), the vendored trees under /opt, the Claude
# Code plugins and the model weights. /sbom.sh lists these lines as the last section of /SBOM.txt (docs/manual/supply-chain.md "Software bill of
# materials"); /test-sbom.sh fails when a line's installer no longer exists, a version probe gives nothing, or an installer
# brings something no line here names - so this file cannot rot silently. One line per component:
#
#   <name> <version> - <license> - <upstream> - <installer>
#       <name>      no spaces; <version> a literal, or $(command) run in the image by sh when the file is generated (its
#                   output's words joined with commas: two node trees read v1,v2); the installed version where a command
#                   reports one, else the installer's pin read from /setup/install-*.sh, else the vendored tree's own record
#       <license>   the upstream repository's LICENSE as its SPDX identifier (several: `A OR B`); where a file in the image
#                   says otherwise, the comment above the line says so
#       <upstream>  where the code comes from; <installer> the setup/install-*.sh that brings it, or the /opt tree the
#                   Dockerfile's ADD Container-Root puts in place (the tree's VENDORED.md names its upstream commit)
#   dpkg:<package> - <license> - <upstream> - <installer>       an installed deb that ships no /usr/share/doc/<package>/copyright
#   npm:<package> - <license> - <upstream> - <installer>        an npm package whose package.json declares no license, or only
#                                                                 points at a file (SEE LICENSE IN <file>, UNLICENSED)
#   python:<distribution> - <license> - <upstream> - <installer>    a Python distribution whose metadata declares no license
#   none:<installer> - <why>                                    an installer that brings no third-party code at all
# A line of any other shape fails the generation, and with it the build. ` - ` (space, hyphen, space) separates the fields and
# appears nowhere inside one.
